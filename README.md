# MRI Safety Thesis — Analysis Code & Data

**Author:** Daniel Juarez Luna  
**Institution:** Creighton University, MSc Physics  
**Advisor:** Michael G. Nichols, PhD.

## Overview

This repository contains the Jupyter notebooks, raw data, and generated figures
supporting my MSc thesis on MRI safety — specifically the characterization of
translational force and torque exerted by a 3T MRI scanner on implantable or
nearby objects, as a function of magnetic field gradient and field strength.

The clinical analysis pipeline follows **ASTM F2052-15** (*Standard Test Method
for Measurement of Magnetically Induced Displacement Force on Medical Devices in
the Magnetic Resonance Environment*).

## Repository Structure

### `JupyterLab/Translational/`
Contains the original translational force experiment from the lab setup:
raw angle measurements, cleaned datasets, and susceptibility fitting.
- **`FitSus.ipynb`** — Main analysis: susceptibility fitting, tan(α) vs dB₀/dz,
  uncertainty propagation via standard error formulas. Referenced in the
  methodology section of the thesis.
- **`AppendixB.ipynb`** — Appendix material and supplementary analysis.
- `RawMeasurments.csv`, `RawMeasurmentsMagneticfield.csv`, `RawMeasurmentsMagneticfieldGrad.csv` — Raw experimental data.
- `cleanData.csv`, `cleanDatawstdsem.csv` — Processed datasets with std and SEM.
- `FitSus.html`, `FitSus_files/` — Exported notebook with inline figures.
- `Assests/` — Final publication-quality figures.
- `Mini Project exploration/` — Early vector potential exploration (Mathematica + notebook).

### `JupyterLab/Torque/`
Custom torque sensor development and MRI torque measurements.
- **`Calibration/`** — Sensor calibration notebooks and data. The sensor was
  custom-built from different materials as a strain detector; calibration involved
  applying known weights to convert voltage readings to force (mg).
  - Key notebooks: `Torque-plots.ipynb`, `Upright-Torque-plots.ipynb`, `data_compiler.ipynb`
  - `dataTorque/`, `New_dataTorque/` — First and updated calibration datasets.
  - `compiled_torque_*.dat`, `compiled_upright_torque_*.dat` — Compiled run files.
  - `df_merged.csv` — Merged calibration dataframe.
  - Fit figures: `inverseRfitFr.png`, `powerFitFr.png`, `rod_characteristics_table.png/tex`,
    `table_min_detect_mass_alt.png`
- **`MRIForces/`** — Actual torque experiments in the lab.
  - **`Torque Presentation.ipynb`** — Helmholtz coil trials (controlled B field).
  - **`Torque_again.ipynb`** — Neodymium magnet trials with increasing B field.
  - Note: angle-dependent measurements were ultimately inconclusive due to
    precision limitations; the B-field magnitude experiments are the reported results.

### `JupyterLab/ClinicalData/` ⭐ PRIMARY CLINICAL ANALYSIS
Real magnetic flux density measurements taken inside and around the 3T MRI scanner
using a gaussmeter mounted on a custom radial fixture. Grid labels (e.g. G3, G6,
A3, D3) refer to fixture coordinates. Analysis follows ASTM F2052-15.

- **`MappingBField/`** — Static B-field characterization across all fixture coordinates.
  - **`ClinicalBfieldAnalysis.ipynb`** — Full pipeline: load CSVs → remove outliers →
    crop static ends → split sub-runs → map time→position (SI units: T, m) →
    compute B, dB/dz, and B·∇B via central differences → summary table.
    Saves `outputs/clinical_summary.pkl` for downstream use.
  - **`G6ClinicalBfieldAnalysis.ipynb`** — Earlier G6-only analysis (superseded by
    the full pipeline above, kept for reference).
  - **`GaussmeterReps.ipynb`** — Repeatability study of field measurements
    (WIP, being continued by junior students).
  - `DataCollectionFolderMRIProject/` — Raw CSV files per grid position and trial
    (coordinates: 00, A3, A6, D3, G3, G6; runs N1–N4). Also available as `.7z`.
  - `betterPlots/` — Per-coordinate figures: B vs position, dB/dz, B·∇B
    (generated by `ClinicalBfieldAnalysis.ipynb`).
  - `G6betterPlots/` — Earlier G6-only figures (from `G6ClinicalBfieldAnalysis.ipynb`).
  - `repeated_flux_analysis.png` — Repeatability figure from `GaussmeterReps.ipynb`.
  - `outputs/clinical_summary.pkl` — Serialized summary DataFrame for downstream use.

- **`TranslationalExperiment/`** — Pendulum deflection test per F2052-15 §8.
  - **`Translational_F2052.ipynb`** — Full F2052-15 pipeline: parse raw CSV →
    correct for equilibrium offset → compute α = arcsin(x/L) and tan(α) →
    average across trials (§9.1) → force ratio FR = tan(α) → Appendix X3
    extrapolation. Saves `outputs/mean_results.pkl` for downstream use.
  - `Translational Data taken around G6 - Sheet1.csv` — Raw hand-recorded
    pendulum displacement measurements for Ti Coil, Bipolar Epicardial Lead
    (Medtronic STREAMLINE 6942), Ti Straight Rod, and 316L Stainless Steel.
  - `F2052_FR_vs_position.png`, `F2052_max_FR_comparison.png` — Output figures.
  - `outputs/mean_results.pkl`, `outputs/translational_summary.pkl` — Serialized
    outputs for downstream use.

- **`MRI_F2052_Comparison.ipynb`** — Cross-analysis notebook linking both pipelines.
  Loads pre-computed `.pkl` outputs (no re-execution of upstream notebooks).
  Identifies test location per §8.1, extracts measured B₀ and |∇B| from the
  field map, runs Appendix X3 Eq. X3.9 extrapolation for all devices at 1.5T
  and 3T, and produces a consolidated F2052-15 compliance report.

- **`Map_translational.ipynb`** — Earlier combined mapping and translational
  notebook (superseded by the split pipeline above, kept for reference).

- `comparison_FR_per_coordinate.png` — Predicted force ratio per device at each
  fixture coordinate.
- `comparison_allowable_gradient.png` — Maximum allowable |∇B| per device vs
  clinical scanner limits (F2052-15 Appendix X3).

### `JupyterLab/BfieldSIM/`
Numerical simulation and early mapping of the static magnetic field.
- **`Bfield.ipynb`** — Solenoid B-field simulation used for the background field
  plot in Section 2.1.1 of the thesis. Purely theoretical illustration.
- **`BfieldAnalysis.ipynb`** — Analysis of gaussmeter mapping data.
- **`BfieldMapping.ipynb`** — Field mapping notebook.
- **`FieldMapping.ipynb`** — Additional field mapping analysis.
- `BfieldMapData/` — Raw gaussmeter CSV files (`gm2_set_5` through `gm2_set_10`)
  and landmark Excel files used for spatial registration.

### `JupyterLab/FindSampleRateMagFieldMap.ipynb`
Exploratory notebook testing the gaussmeter's data acquisition rate under low
magnetic flux conditions. Result: 0.25 s sampling interval was selected for that
run, though subsequent analysis suggested 0.5 s would have been more appropriate.

### `JupyterLab/Poster1/`
Early notebook used to reproduce figures from a prior student's thesis on RF
heating, created while learning Python/Jupyter at the start of the project.
Included for completeness.

### `MapField/`
Raw gaussmeter acquisition `.dat` and `.csv` files from the sample rate
characterization runs (3 separate test sessions, 2–5 runs each).

## Clinical Analysis Pipeline

The three notebooks in `ClinicalData/` form a linked pipeline:

```
ClinicalBfieldAnalysis.ipynb          Translational_F2052.ipynb
   (MappingBField/)                      (TranslationalExperiment/)
         │                                         │
         │  outputs/clinical_summary.pkl           │  outputs/mean_results.pkl
         └──────────────────┬───────────────────────┘
                            ▼
                 MRI_F2052_Comparison.ipynb
                  (cross-analysis & report)
```

To refresh the comparison after new data: re-run the relevant upstream notebook
(it will overwrite its `.pkl`), then re-run Cell 1 of the comparison notebook.

## Dependencies

Core libraries used across all notebooks:

```
pandas, numpy, scipy, matplotlib
```

To install:
```bash
pip install pandas numpy scipy matplotlib
```

No additional libraries required. Inter-notebook data exchange uses Python's
built-in `pickle` — no parquet engine needed.
